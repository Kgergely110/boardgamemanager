# Security Policy

## Supported Versions

This project is currently pre-1.0. Security fixes are provided for the current `0.1.x` development line. Older versions and commits may not receive security updates; upgrading to the latest available version is recommended.

| Version | Supported |
| --- | --- |
| `0.1.x` | Yes |
| `< 0.1.0` | No |

## Reporting a Vulnerability

Please report suspected vulnerabilities privately. If GitHub's private vulnerability reporting is enabled for this repository, use **Security → Advisories → Report a vulnerability**.

If private reporting is unavailable, contact the repository maintainers through a private contact method listed on the repository owner's GitHub profile. Do not post vulnerability details, proof-of-concept code, or sensitive information in a public issue, discussion, or pull request. If no private contact method is available, open a public issue requesting one without describing the vulnerability.

When possible, include:

- The affected version or commit and component.
- The impact and conditions required to trigger the issue.
- Clear reproduction steps or a minimal proof of concept.
- Relevant environment details, such as operating system, Node.js, database, or deployment method.
- Any known workaround or mitigation.

Please use a local or otherwise authorized instance for testing. Redact passwords, access tokens, personal information, and other sensitive data from reports and logs.

Maintainers will review reports privately and coordinate remediation and disclosure with the reporter where practical. No fixed response or resolution timeline is currently offered.
